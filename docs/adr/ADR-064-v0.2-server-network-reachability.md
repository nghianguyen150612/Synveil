# ADR-064: v0.2 server network reachability

Status: Accepted

Date: 2026-10-04

Decision owners: Synveil maintainers

## Context

Managed hosting needs useful local and remote access without turning raw bind
addresses, proxy syntax, TLS keys, or firewall commands into product choices.
The prior service topology deliberately left the API on loopback.

## Decision

Managed Host keeps Axum on `127.0.0.1:3000`; PostgreSQL remains on its private
managed endpoint. A finite `LocalOnly`, `PrivateLan`, and
`AdvancedExternalHttps` model controls only a separate HTTPS edge. Broadening
always requires a reviewed plan and explicit confirmation. The durable UUIDv7
network integration identity is written in `Preparing` before side effects and
retained through repair.

Caddy is the initial Linux managed edge, separately owned and least-privileged.
Its production artifact is not qualified until exact version, provenance,
inventory, license and SHA-256 evidence exist. Advanced external mode may use
an operator-owned proxy. There is no mandatory relay and no router, UPnP,
NAT-PMP, PCP, DNS, or operator proxy mutation.

The configured HTTPS canonical origin is the existing API Origin/CSRF
authority. Managed private CA, public WebPKI, and operator-managed HTTPS are
distinct trust modes. Private CA trust is profile-scoped, distributed only by
a trusted later onboarding boundary, and performs normal chain, validity and
name verification. Trust-all, TOFU, hostname bypass, and insecure off-loopback
HTTP are forbidden. The CA and leaf use distinct protected credential IDs;
the CA key is never mounted into the edge.

Private LAN candidates are typed observations, not interface-name guesses.
Only an explicitly selected suitable private address is bound; wildcard,
public, link-local, tunnel, and container candidates fail closed. Address loss
needs attention and never selects another interface. Supported active `ufw` or
`firewalld` adapters may create one identified scoped HTTPS rule after consent.
Foreign rules are preserved; ambiguous ownership needs attention. PostgreSQL
and backend ports are never opened.

## Consequences

LocalOnly has a loopback HTTPS edge and no firewall change. PrivateLan has one
explicit LAN listener and managed private trust. AdvancedExternalHttps proves
an operator-owned strict HTTPS origin but does not rewrite external systems.
Mode narrowing removes only owned exposure. Repair may restore exact edge
integration or renew a leaf under the same CA, but may not rotate a CA,
reselect an interface, broaden a firewall, or change mode silently.

## Alternatives

Direct public API binding, plaintext LAN endpoints, automatic router exposure,
mandatory proprietary relay, and a new in-process proxy were rejected.

## Migration and review trigger

Review when a production Caddy artifact is qualified, a managed ACME adapter
is proposed, or non-Linux managed hosting is qualified. P035 owns first admin;
P036 owns the clean-machine composed Host journey.
