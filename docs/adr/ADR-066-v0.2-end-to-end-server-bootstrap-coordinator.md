# ADR-066: v0.2 end-to-end Server Bootstrap Coordinator

Status: **Accepted**

Date: 2026-10-04

Decision owners: Synveil v0.2 guided-hosting maintainers

## Context

P031--P035 own configuration, server object storage, dependencies/services,
reachability, and first-admin bootstrap. The Host journey needs one composition
boundary without creating a competing authority or sync engine.

## Decision

One Server Bootstrap Coordinator derives a finite product state from fresh
canonical-owner observations. Host starts only after explicit intent. A plan
binds the config generation, identities, owner plans, platform qualification,
artifacts, and bounded privileged effects; mutation requires review and rejects
stale generations. Personal/Home asks only for server storage, reachability,
and owner credentials. Privilege is short-lived and purpose-specific.

`Ready` is derived only after the full service, PostgreSQL 17 identity,
migration, storage, network/HTTPS, bootstrap-closed, explicit-login, health,
and initial logical Library/root proof. Uncertain effects are inspected before
retry. The coordinator owns neither client sync nor durable owner truth.

P037 owns the unified Host-or-Connect Welcome. P038/P039 consume the safe
origin/trust handoff. P040 owns client library and local-folder onboarding.

## Consequences

Native adapters remain responsible for invoking P031--P035. Existing partial
setups resume from owner state, and unknown/foreign state fails closed. The
desktop cannot request arbitrary root commands through this API.

## Alternatives

A QML page-number state machine and a second all-in-one provisioner were
rejected because both duplicate durable authority and make recovery unsafe.

## Migration and review trigger

Revisit only if a canonical owner boundary changes or a supported non-systemd
managed platform requires a different bounded adapter.
