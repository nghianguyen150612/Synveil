# ADR-068: v0.2 simplified connection setup

Status: Accepted — Prompt038

## Context

ADR-043 makes the client the single durable profile owner. Fresh users should
not need to understand profiles, canonical origins, or URL scheme syntax.

## Decision

Fresh Connect asks only for **Server address**. A bounded Rust
`UserServerAddress` trims outer whitespace, supplies `https://` only when no
scheme is present, then delegates to `CanonicalBaseUrl`. Explicit HTTP and all
other unsupported schemes are rejected. A host-based display label is derived
only after parsing.

QML performs no HTTP or persistence. DesktopController, local IPC, and
synveil-client remain authoritative; the readiness probe succeeds before the
single writer persists. The opaque profile ID stays stable. Origin changes use
ADR-043 credential fencing. An unknown IPC outcome triggers authoritative
refresh and intended origin/profile reconciliation, never blind replay.
Authentication remains P039.

## Consequences

Connect is one field and one action while HTTPS verification, redirect policy,
probe bounds, generation fencing, and durable ownership remain unchanged.
Private-CA enrollment is not inferred from an opaque trust descriptor.
