# ADR-072: v0.2 repair and recovery UX

Status: Accepted — Prompt042
Date: 2026-10-06
Owners: Synveil desktop, client, client-sync and installation maintainers

## Decision

Refine ADR-048’s Rust-owned derived recovery projection, retaining all canonical
controller/profile/authentication/root/runtime/attention/setup owners. Finite
presentation state and capability separate actionable recovery from automatic
waiting and installation guidance. No durable recovery journal, database,
supervisor, profile editor or installer is introduced.

Restore missing folder means restore access to the same root and invoke the
existing bounded wake. Missing roots never mean empty trees or remote deletes.
Wrong marker, binding and redirected roots remain fail-closed.

Repair Synveil is guidance only: desktop has no verified same-version Windows
artifact resolver or approved graphical repair invoker. AppImage integration
and native package lifecycle remain their owners; no guessed repair command
runs. Upgrade is never relabeled Repair.

BackgroundClientManager composes existing supervised stop and launch only when
Linux full-stop evidence is available and the kernel control-endpoint peer
matches the service MainPID. The same gate excludes concurrent start
and restart, and retains uncertain Stopping/Starting admission until inspected.
Acknowledgement is never readiness. Windows/direct-process restart is guidance
until a safe full-stop proof exists. Native service work uses fixed owned
commands asynchronously under explicit timeouts; there is no forced/process-name kill.

Reconnect uses the P038 form, preserving canonical validation and credentials.
Unknown profile/root-check outcomes retain transient admission until a fresh
newer snapshot, and retries require current status. These fences are not durable
product truth; GUI reopen reconstructs state from canonical owners.

## Consequences

All durable state, user pause, conflicts, pending identities and P041 first-sync
evidence survive recovery. QML renders safe typed values and accessible product
copy. Unsupported mutations remain unavailable or guidance only. Native and
clean-machine acceptance remain separate Phase-G evidence; P043 is deferred.
