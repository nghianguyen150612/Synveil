# ADR-053: v0.2 installation transaction journal

- Status: **Accepted — Prompt008 contract**
- Date: 2026-09-28
- Decision owners: Distribution, Platform, Security, Desktop

## Context

Prompt007 deliberately executes in memory. A process can disappear after an OS
mutation may have begun but before its result is known. Repeating that effect is
not safe, and a missing or damaged recovery record cannot imply completion.

## Decision

Extend `synveil-install-engine` with a small append-only file journal, not a
database. Bind its independent schema-1 chain to SHA-256 of the exact validated
plan and use the stable plan ID as transaction storage identity. Hold one OS
exclusive writer lock across replay and execution.

Commit immutable contiguous generations through create-new temporary write,
file synchronization, no-replace promotion, and directory synchronization.
Persist `EffectMutationStarted` before invoking every effect. An unmatched start
on recovery is `OutcomeUnknown`; reconcile authoritative state and never blind
replay. Reverify earlier effects without applying them. Treat ambiguous
compensation, partial mutation, corruption, gaps, missing resume state, and plan
mismatch as closed stops. Persist successful final verification before durable
transaction completion.

The fingerprint and hash chain detect local identity/corruption; they are not
publisher authentication. P006 owns release trust. P009 owns lifecycle policy,
and P010 owns user-facing errors.

## Consequences

Process restart can distinguish fresh, incomplete, uncertain, and complete
transactions without granting duplicate-mutation permission. Storage stays
inspectable, bounded, offline, and independent of client SQLite/PostgreSQL.
Callers must choose platform roots and preserve installer-owned runtime state.

Safe Rust file and directory syncing improves crash durability, but native
filesystem/device guarantees vary. Fixture tests are not physical/VM power-loss
or clean-machine evidence; later platform acceptance must prove those claims.

## Alternatives

Mutable snapshots were rejected because overwrites obscure the last durable
generation. SQLite and other embedded databases were rejected as disproportionate
and as risking ownership confusion. Automatic fresh fallback and blind replay
were rejected because absence or ambiguity is not evidence that mutation did
not occur.
