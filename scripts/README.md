# Project scripts

This directory is reserved for repeatable, non-secret project commands. Normal
Rust build, format, check, and test operations use Cargo directly; no shell
script is required by the repository skeleton.

The release-specific commands are:

```text
./scripts/test-desktop-ui.sh
./scripts/validate-release-artifacts.sh \
  --manifest=target/packages/SYNVEIL-LINUX-ARTIFACT-MANIFEST.txt
./scripts/validate-install-acceptance.sh
```

The installation acceptance command validates the static v0.2 JSON scenario
contract and runs focused standard-library self-tests. It does not install or
launch Synveil and is not native clean-machine evidence.

The validator consumes the manifest generated by `deploy/packages/build.sh`.
That manifest records the current source-tree fingerprint, toolchain, archive
timestamp, binary sizes, ELF build IDs, and SHA-256 values. It is a generated
provenance record, not a checked-in expected binary hash; a dirty-tree build
must never be compared with a clean-checkpoint artifact.
